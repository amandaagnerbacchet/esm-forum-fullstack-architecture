# Planejamento de Pair Programming

Como este projeto pode ser executado individualmente ou em dupla, adotamos a seguinte estratégia para a aplicação do **Pair Programming**:

## Estratégia de Aplicação
- **Divisão de Papéis:**
  - **Driver (Condutor):** Responsável por digitar o código e estruturar os arquivos.
  - **Navigator (Navegador):** Responsável por revisar o código linha a linha e pensar na lógica geral.
- **Rotação:** Alternância de papéis a cada funcionalidade implementada ou blocos de tempo.

## Ferramentas Utilizadas
- **VS Code Live Share:** Para colaboração em tempo real no código-fonte.
- **Discord / Google Meet:** Para comunicação por voz contínua e alinhamento de ideias.
