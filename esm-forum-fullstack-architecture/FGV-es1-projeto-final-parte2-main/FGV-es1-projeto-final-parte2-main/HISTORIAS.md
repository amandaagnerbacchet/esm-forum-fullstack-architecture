# Histórias de Usuário e Priorização - ESM Forum

Este documento apresenta as Histórias de Usuário para 3 das funcionalidades planejadas para o ESM Forum, detalhando seus critérios de aceitação e justificativa de prioridade.

---

## 1. Histórias de Usuário

### História 1: Sistema de Votação em Perguntas
- **Formato:** **Como** usuário do fórum, **eu quero** votar em perguntas (upvote/downvote), **para** destacar perguntas úteis e relevantes para a comunidade.
- **Critérios de Aceitação:**
  - [ ] Cada pergunta exibirá botões de upvote e downvote na interface.
  - [ ] O contador total de votos deve ser atualizado instantaneamente ao interagir.
  - [ ] O usuário pode alterar o seu voto (de upvote para downvote ou vice-versa).
  - [ ] O sistema impede múltiplos votos do mesmo usuário na mesma pergunta.

### História 2: Busca de Perguntas por Palavra-Chave
- **Formato:** **Como** visitante ou usuário do fórum, **eu quero** buscar perguntas utilizando palavras-chave, **para** encontrar rapidamente tópicos de meu interesse sem precisar navegar por páginas inteiras.
- **Critérios de Aceitação:**
  - [ ] A interface deve disponibilizar uma barra de pesquisa acessível no topo.
  - [ ] O sistema deve filtrar as perguntas no banco de dados com base nos termos digitados.
  - [ ] Os resultados devem ser exibidos de forma clara em uma lista filtrada.
  - [ ] Se nenhum resultado for encontrado, uma mensagem informativa deve ser exibida.

### História 3: Categorização de Perguntas por Tags
- **Formato:** **Como** autor de uma pergunta, **eu quero** adicionar tags/categorias (ex: tecnologia, carreira, dúvidas-gerais) ao publicá-la, **para** organizar o conteúdo por assunto e facilitar a filtragem.
- **Critérios de Aceitação:**
  - [ ] O formulário de criação de perguntas deve conter um campo para seleção ou digitação de tags.
  - [ ] As tags devem aparecer visíveis nos cards de exibição das perguntas no feed.
  - [ ] O usuário deve conseguir clicar em uma tag para visualizar apenas as perguntas associadas a ela.

---

## 2. Priorização das Histórias

As histórias foram ordenadas com base no valor para o usuário e impacto no engajamento da plataforma:

1. **Sistema de Votação em Perguntas (Alta Prioridade):** Escolhida como primeira prioridade porque o engajamento e a curadoria comunitária são o coração de um fórum de perguntas e respostas.
2. **Busca de Perguntas por Palavra-Chave (Média/Alta Prioridade):** Essencial para a usabilidade à medida que a quantidade de perguntas na base de dados cresce.
3. **Categorização de Perguntas por Tags (Média Prioridade):** Importante para a organização estrutural do conteúdo a médio e longo prazo.
